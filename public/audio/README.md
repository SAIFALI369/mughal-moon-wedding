# Wedding soundtrack

The invitation includes six gentle local instrumentals, selected through the floating playlist or Simran chat. The first track is the existing Balagal Ula Bi Kamalihi arrangement; the five new synthesized pieces are Moonlit Dua, Rosewater, Royal Courtyard, Sufi Breeze and Evening Mehfil.

These are not recorded or sung qawwali performances. No commercial artist recordings were downloaded. The new original instrumental loops are generated by `scripts/generate-music.py` (Python + imageio-ffmpeg). Production uses the included MP3 files, with no generation dependency. The original WAV remains as a source for the first MP3.

To override the first track, upload a licensed recording and set `CUSTOM_MUSIC_URL` in `src/components/wedding/config.ts`. Update the shared playlist labels if the recording changes. Never publish music you lack permission to distribute.

See `docs/gallery-and-music.md` for playback behavior and deployment requirements.
