# Theme loops

Generated by `node scripts/build-theme-loops.mjs` — do not edit by hand.

Each file is an 8-second, silent, 1024×576 H.264 loop built from the theme's own
illustration in `src/assets/themes`: a slow camera move plus its ambient layer
(petals, embers, stars or lantern bokeh). The still illustration stays the poster
frame, so the video only streams in after the first paint.
